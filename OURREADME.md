# Canyon of the Lost Engines (Team: Gear & Grit)

## Overview
A text-based steampunk-Western adventure where you collect 3 Core Fragments from wrecks (Rusted Titan, Boiler Gulch, Smokestack Spire) to power an airship and escape. Face the Iron Phantom in a final showdown!

## Requirements
- Python 3.12.6

## How to Run
1. Clone the repository to your local machine.
2. Navigate to `project_code/src/` in the terminal.
3. Run `python main.py`.

## Gameplay
- **Start**: Choose a class (Scrapper, Gearshot, Steamwright, Rustblade) and name your character.
- **Explore**: Randomly visit wrecks for events (combat, puzzles, loot, recruitment).
- **Events**: Select a party member and stat; success depends on stat matches (e.g., Strength for combat).
- **Party**: Gain members via recruitment, lose them if vitality hits zero.
- **Goal**: Collect 3 Core Fragments, then defeat the Iron Phantom to win.

## Tips
- Use Dexterity for loot, Strength for combat, Intelligence for puzzles.
- Keep vitality high to survive.
